# Forecasting-NBA-Player-Performance
This project attempts to predict an NBA player’s future performance using historical season statistics. Specifically, I targeted the Box Plus/Minus metric, which is widely used in basketball analytics to estimate a player’s overall performance and impact. I trained three machine learning models: XGBoost, LightGBM, and Random Forest, on engineered features specifically designed to capture and summarize players’ past-season statistics. These features include lagged statistics from prior seasons, short-term rolling averages, and exponentially weighted means (EWM) for players’ careers up to the current season. I also implemented time-aware cross-validation to avoid information leakage and compared performance against BPM from the player’s previous season.
